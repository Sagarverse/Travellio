# Travellio ✈️🌍

**Your Digital Tour Companion**

Travellio is a comprehensive travel application designed to be the ultimate digital companion for tourists. It functions not only as an interactive tour guide but also intelligently collects and organizes your travel data and memories.

---

## ✨ Features
*   **Interactive Guides**: Discover points of interest with integrated smart routing.
*   **Memory Collection**: Automatically organizes photos and notes by location.
*   **Offline Mode**: Essential features remain available even without an internet connection.
